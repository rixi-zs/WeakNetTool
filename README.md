# WeakNetTool 使用说明

Windows 弱网测试小工具。用 [WinDivert](https://github.com/basil00/WinDivert/releases/tag/v2.2.2) 在网络层
**丢包 / 限速**，用来模拟断网、丢包、网络慢。

- **必须用管理员身份运行**（要装内核驱动）
- 构建后有两个程序：`WeakNetToolGUI.exe`（图形界面）、`WeakNetTool.exe`（命令行，适合写脚本）
- 在本机接管匹配的流量；正常停止时关闭 WinDivert 句柄。异常退出后的网络恢复仍需在可恢复的测试环境中验证

## 一、图形界面（推荐）

双击 `WeakNetToolGUI.exe`，会弹一次 UAC。

```
┌─ 拦截设置 ────────────────────────────────────────────────┐
│  丢什么：  ( )全部端口（整体断网）                         │
│            ( )按端口   [8080]                              │
│            ( )按进程名 [chrome.exe] [浏览…]                │
│  拦截范围：方向 [both▾]     端口匹配 [src▾]  协议 [TCP+UDP▾]│
│  网络质量：丢包率(%) 下行[100] 上行[100]                   │
│            限速      下行[0]   上行[0]                     │
│  过滤器：  (inbound or outbound) and …       ← 实时预览 │
└────────────────────────────────────────────────────────────┘
                 [开始拦截]  [停止丢包]
```

**四步**：

1. 选**丢什么**（全部端口 / 某个端口 / 某个进程）
2. 选**拦截范围**（方向、协议）
3. 填**丢包率**或**限速**
4. 点**开始拦截**；想恢复点**停止丢包**

另外三页（顶部标签）：**活动**、**全局快捷键**、**运行日志**。

- **活动**：尝试通过 ETW 显示各程序的下载 / 上传速度（按进程统计 TCP、UDP 事件；监控启动或事件采集可能失败）。
  点中某一行，右边会显示它的完整路径、PID 和累计流量。
  **双击某一行** = 把这个程序直接填进「拦截设置」，不用手输进程名。
- **全局快捷键**：设置断网 / 联网键
- **运行日志**：出问题时先看这里

> 「活动」页的速率监控用的是 ETW，**同样需要管理员权限**（界面自带提权清单，正常双击就行）。
> 刚切过去可能需要等待 ETW 事件；若监控启动失败，请查看界面提示和运行日志。

## 二、三个最常见的需求

### 1. 我要"断网"（最简单）

| | 填什么 |
|---|---|
| 丢包率 | 下行 `100`、上行 `100`（**默认就是这样**） |

`100` = 全部丢弃。直接点「开始拦截」即可。

### 2. 我要"丢一部分包"

| | 填什么 |
|---|---|
| 丢包率 | 下行 `30`、上行 `30`（按你要的比例） |

`1~99` = 每个包按这个概率丢，没丢中的原样放行。
`0` = 不丢包。

> 丢包率是**上行/下行分开**的。只想影响下载就把上行填 `0`。

### 3. 我要"限速"（模拟网络变慢）

| | 填什么 |
|---|---|
| 丢包率 | 下行 `0`、上行 `0` |
| 限速 | 下行 `0`、上行 `300B`（按你要的速率） |

**限速和随机丢包是两回事**：超速报文通常先排队再回注；队列满、等待超时或发送失败时仍可能丢包。

- 单位：`300B` = 300 **字节/秒**、`200K` = 200KB/s、`2M` = 2MB/s、不写单位按 KB/s
- **可以带小数**：`1.2K` = 1.2KB/s、`0.5M` = 512KB/s
- `0` = 不限速
- ⚠ **只限上行时，方向要改成 `outbound`**（默认是 `inbound`，只限下行）

### 丢包率 / 限速 怎么搭配

| 丢包率 | 限速 | 效果 |
|---|---|---|
| `0` | `>0` | **只设限速**（正常排队；队列限制或故障仍可能导致丢包）← 最常用 |
| `1~99` | `>0` | 两个一起：先按概率丢，活下来的再限速 |
| `1~99` | `0` | 只按概率丢包 |
| `100` | `0` | 全部丢弃（断网） |

## 三、命令行速查

```bat
:: 断网（丢 8080 端口的下行）
WeakNetTool.exe --port 8080

:: 上下行都丢 30%
WeakNetTool.exe --port 8080 --dir both --loss 30

:: 只让某个进程断网
WeakNetTool.exe --process chrome.exe

:: 只限上行 300 字节/秒（不丢包）
WeakNetTool.exe --port all --dir outbound --rate-up 300B

:: 上行限 200KB/s + 上行丢 5%
WeakNetTool.exe --port all --dir outbound --rate-up 200K --loss-up 5

:: 只校验参数、不真的拦（免管理员，用来排查配置）
WeakNetTool.exe --port 8080 --dry-run
```

| 参数 | 说明 |
|---|---|
| `--port <列表>` | 要丢的端口，`8080,8443` 这样逗号分隔；`all` = 全部端口（整体断网） |
| `--process <进程名>` | 只丢这个进程，如 `chrome.exe`（与 `--port` 二选一） |
| `--dir <inbound\|outbound\|both>` | 拦截方向，默认 `inbound`（下行） |
| `--match <src\|dst>` | 端口匹配源端口还是目的端口，默认 `src` |
| `--proto <tcp\|udp\|both>` | 协议，默认 `both` |
| `--loss <0-100>` | 丢包率；`100`=全丢、`0`=不丢、`1~99`=按概率丢 |
| `--loss-down` / `--loss-up` | 只设某一个方向的丢包率 |
| `--rate <速率>` | 限速，如 `300B` / `200K` / `2M` |
| `--rate-down` / `--rate-up` | 只设某一个方向的限速 |
| `--duration <秒>` | 跑多少秒后自动恢复，`0` = 一直跑到手动停止 |
| `--hotkey-block` / `--hotkey-unblock` | 全局快捷键断网 / 联网 |
| `-v` | 打印被丢弃的报文 |
| `-q` | 不打印周期性统计 |
| `-h` | 完整帮助 |

**退出码**：`0` 正常 · `1` 运行出错 · `2` 参数错误 · `3` 没用管理员运行

## 四、全局快捷键

界面「全局快捷键」页里，或命令行 `--hotkey-block` / `--hotkey-unblock`：

- 支持**单键**（`F8`）、**组合键**（`Ctrl+Alt+B`）、**鼠标侧键**（`X1` / `X2`）
- 窗口不在前台也有效
- **两个键设成同一个** = 切换键：按一下断网、再按一下联网
- 单键会**全局独占**该键（别的程序收不到它），界面会提示

## 五、注意事项

1. **必须管理员权限**，否则打不开驱动（错误码 5）。
2. **本机自测**（客户端和服务端都在同一台机器）时，回环流量**只在 `outbound` 方向可见**。
   请把方向设为 `outbound`、端口匹配设为 `src`。
3. **限速在极低速率下会让 TCP 卡死**（不是 bug）：一个 1500 字节的包在 300 B/s 下要攒
   5 秒令牌，而 TCP 的重传超时只有秒级。UDP 或小包交互型流量不受此限。
4. **限速只作用于被接管的流量**。进程模式下，没命中目标进程的报文仍全速通过。
5. 驱动是**全局**的：同一时间只开一个 WeakNetTool 实例比较稳妥。

## 六、出问题了

| 现象 | 原因 / 怎么办 |
|---|---|
| 错误码 **193** | 用错位数的 DLL。64 位程序配 `x64\WinDivert.dll` |
| 错误码 **3** | 驱动加载不了：`WinDivert.dll` 和 `WinDivert64.sys` 必须和 exe **放同一目录**（中文路径没问题） |
| 错误码 **1450** | 系统资源不足，通常是杀毒软件/EDR 拦截驱动。先关掉安全软件试试 |
| 错误码 **5** | 没用管理员权限 |
| 打开就闪退 / 被杀软拦 | Smart App Control 或 WDAC 拦截未签名 exe，需换签名版或加白名单 |
| 快捷键按了没反应 | 被别的程序占用了；看界面「热键状态行」会写明原因 |

**排查万能招**：exe 同目录下的 `weaknet_debug.log` 记录了每一步（每行立即落盘），
出问题时先看它。界面菜单 **工具 → 查看调试日志** 可以直接打开。

先用 `--dry-run` 跑一遍能免管理员校验参数和过滤器：

```bat
WeakNetTool.exe --port 8080 --dry-run
```
